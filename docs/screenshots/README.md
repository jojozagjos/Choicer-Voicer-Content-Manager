# Screenshots

The images the main README points at. Four are expected:

| File | What to capture |
| --- | --- |
| `editor.png` | A dub pack open in the editor, with clips on the timeline and a caption showing over the video |
| `export.png` | The Export tab with a pack loaded and the line list on the right |
| `library.png` | The Content tab, a type selected, several packs listed |
| `checks.png` | A pack selected with its detail panel showing some issues |

`Win + Shift + S` captures a region on Windows. Around 1400 pixels wide is
plenty; anything larger just makes the repository bigger for no gain.

Take them in **dark mode**, which is what the app opens in, so the set looks
like one app rather than four.
